# 💰 Финансовый трекер

Личное приложение для учёта доходов и расходов. Работает в браузере, без сервера и без сборки.

## Возможности

- Добавление расходов и доходов с категорией, датой и комментарием
- Итоги за выбранный месяц: доходы, расходы, баланс
- Топ категорий расходов с долями — видно, на что тратишь больше всего
- Обновление в реальном времени, в том числе между открытыми вкладками
- Данные хранятся в `localStorage` браузера

## Запуск

Откройте `index.html` в браузере. Ничего устанавливать не нужно.

## Тесты

Нужен Node.js 18+:

```powershell
node --test test.js
```

## Структура

```
index.html   разметка
style.css    стили (тёмная тема)
script.js    логика и отрисовка
test.js      тесты логики
```

## Замечания

- Данные привязаны к браузеру и домену: в другом браузере они не видны.
- Для резервной копии можно сохранить значение `expense-tracker-v1` из localStorage.
